Alongside the models and the write-ups, we've picked up a small collection of one-off scripts for checking on the lab — reading a log, confirming a service is healthy, that kind of thing. This page is a running catalog: what each tool does, where it lives, and how to run it. Nothing here is a product, just utility scripts written as we needed them.

Reports

List-WebUI-Users.bat

Prints every registered Open WebUI account — name, email, role, account-created date, and last-active timestamp — read directly (and read-only) from the lab's Open WebUI database.

Runs on: Lab PC 2 (Node A), console or over SSH.

Usage: double-click the .bat at the console, or run the underlying list_webui_users.py with Python directly.

Open WebUI has no dedicated login-event log — last_active reflects general account activity, not a specific sign-in time.
