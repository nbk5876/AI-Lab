Note 001 — Ollama on AMD Ryzen AI Platform

During installation, Ollama copied AMD ROCm/HIP libraries including:

...Ollama\lib\ollama\rocm_v7_1\ggml-hip.dll

Observation: No separate AMD ROCm install was required — Ollama bundles what it needs for the Ryzen AI platform.

Note 002 — Ollama Launch UI

Ollama displayed a Launch page with agent integrations such as Claude Code, Codex App, Hermes Agent, OpenClaw, and OpenCode.

Note 003 — Ollama Install Footprint

Ollama consumed about 5 GB of disk before any models were downloaded.

Note 004 — Model Downloads Use Layers

Ollama downloads models in layers, similar to how container images work.

Note 005 — Qwen2.5-Coder Behavior

Qwen2.5-Coder:14B is a coding-oriented model. In Open WebUI, it attempted to emit JSON-style tool calls in response to simple conversational questions. This appears to be expected model behavior, not a broken installation.

Important lesson

Coder models are not necessarily ideal as everyday chatbots — they're tuned for code and tool-use patterns, which can leak into casual conversation.
